## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的数据既需要按主键快速定位，也需要按排序键做范围查询，两套索引经常不一致。请从零实现一个有序哈希双索引组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 同时维护哈希索引（主键定位）与有序索引（排序键范围查询），同一份数据两处引用；2) 写入与删除必须同时更新两个索引，任何一侧失败都要回滚，不得出现只更新一侧的中间状态；3) 支持一致性检查：全量扫描两个索引并比对条目集合，发现不一致要输出差异明细而不是只报错；4) 支持修复：根据差异自动从一侧修复另一侧，修复要幂等并统计修复条数；5) 支持排序键更新：更新排序键时要先从有序索引移除再插入新位置，过程中不得让查询看到重复条目；6) 支持并发读写：查询与写入并发进行时不得读到"索引已更新但数据未更新"的状态；7) 提供统计：两索引条目数、更新次数、检测到的不一致次数与修复条数；8) 测试覆盖双索引同步更新、失败回滚、一致性检查与修复、排序键更新、并发一致性与统计；`mvn -q verify` 一条命令跑通。
